 
Abstract 
Cyber threats such as ransomware, trojans, bankers, adware, and related malware families continue to evolve through obfuscation, polymorphism, API substitution, and increasingly sophisticated execution strategies, thereby reducing the effectiveness of traditional signature-based and static machine learning detection systems. Existing approaches commonly rely on handcrafted features or static behavioral representations that fail to adequately capture the temporal evolution, semantic context, and structural dependencies inherent in malicious system activity. Although recent Graph Neural Network (GNN)-based approaches improve structural behavioral modeling, many existing methods continue to represent execution traces as static graphs and lack robust integration of temporal execution dynamics and semantic contextual understanding. Current threat detection research exhibits a fundamental limitation in simultaneously modeling three critical dimensions of malicious behavior: temporal dynamics, semantic robustness, and heterogeneous structural relationships. Conventional machine learning approaches frequently discard execution ordering and relational dependencies, while existing GNN architectures often overlook temporal characteristics such as operation timing, acceleration, and burst behavior. Similarly, recent Large Language Model (LLM)-based semantic approaches improve contextual interpretation of API behavior but remain limited in modeling evolving execution dynamics over time. As a result, existing systems may struggle to reliably distinguish rapidly evolving malicious behavior from legitimate software performing structurally similar operations across longer execution intervals. This thesis proposes a heterogeneous Temporal Graph Neural Network (TGNN) framework for dynamic threat detection using integrated semantic and temporal behavioral features. System execution traces collected from sandbox environments are transformed into schema-aware heterogeneous graphs in which API calls, processes, files, registry objects, and network interactions are represented as typed nodes connected through typed temporal relations. To improve robustness against API obfuscation and behavioral variation, node representations are enriched using LLM-based semantic embeddings generated through pretrained sentence-transformer models. The proposed architecture further integrates heterogeneous graph message passing, Hybrid GAT-SAGE aggregation, bidirectional LSTM-based temporal sequence modeling, and engineered temporal behavioral features including operation frequency, acceleration, and burst activity characteristics. In addition, an adaptive three-branch gated fusion mechanism is employed to jointly integrate semantic, structural, and temporal behavioral representations for threat classification. The proposed system aims to classify behavioral activity into Threat and Benign categories while improving robustness against previously unseen threat variants and evolving attack strategies. The framework will be evaluated against static machine learning baselines sequential deep learning models, static GNN architectures, and LLM-based behavioral approaches using evaluation metrics including accuracy, precision, recall, F1-score, AUPRC, false positive rate, and time-to-detect performance. Furthermore, a leave-family-out evaluation protocol will be employed to assess the generalization capability of the framework across previously unseen threat families. By integrating semantic understanding, temporal execution dynamics, and heterogeneous structural reasoning within a unified architecture, the proposed framework aims to improve behavioral threat detection and provide a stronger foundation for dynamic cybersecurity analysis in evolving threat environments.

1 Introduction
The growing dependence on digital infrastructure, cloud computing, and interconnected systems has significantly increased the scale and complexity of modern cybersecurity threats~\cite{bilot2024survey}. Malicious software such as ransomware, trojans, bankers, spyware, and related malware families continues to evolve through sophisticated techniques designed to evade conventional security mechanisms~\cite{bilot2024survey,amer2025graphshield}. These threats frequently employ obfuscation, polymorphism, API substitution, and behavior-altering execution strategies, making reliable threat detection increasingly challenging in modern computing environments~\cite{bilot2024survey,amer2025graphshield}. Among these threats, ransomware has emerged as one of the most disruptive forms of cyber attack due to its ability to encrypt critical data, interrupt organizational operations, and cause substantial financial and operational damage~\cite{bilot2023intrusion,amer2025graphshield}. The increasing frequency of attacks targeting healthcare systems, financial institutions, government organizations, and industrial infrastructure has highlighted the limitations of traditional reactive cybersecurity approaches and emphasized the need for more adaptive and intelligent behavioral detection methods~\cite{bilot2024survey,bilot2023intrusion}. To address these challenges, machine learning and deep learning techniques have increasingly been explored for behavioral malware analysis~\cite{li2024imbalanced,bilot2024survey}. Unlike traditional signature-based approaches that rely on previously observed attack patterns, behavioral analysis focuses on identifying malicious activity through system execution behavior, including API interactions, process activity, file operations, registry modifications, and network communication patterns~\cite{mimura2022nlp,amer2025graphshield}. Recent advances in Graph Neural Networks (GNNs) have demonstrated strong capability in modeling structural relationships between such system entities by representing behavioral activity as graph-structured data~\cite{hamilton2017graphsage,wang2019matchgnet,bilot2024survey}. Similarly, recent developments in Large Language Models (LLMs) and semantic embedding techniques have improved contextual understanding of behavioral operations and execution patterns~\cite{mimura2022nlp}. Despite recent progress, accurately modeling evolving malicious behavior remains a challenging problem due to the complex temporal, semantic, and structural characteristics of modern cyber threats~\cite{bilot2024survey,haghshenas2023temporal}. Consequently, improving behavioral threat detection and strengthening generalization capability against evolving attack variants continues to be an active area of cybersecurity research~\cite{li2024imbalanced,amer2025graphshield}.

1.1 Motivation
The increasing sophistication of modern cyber threats has exposed significant limitations in conventional threat detection systems~\cite{bilot2024survey,guo2023zeroday} . Traditional signature-based security mechanisms primarily rely on previously observed attack patterns, static rules, and handcrafted indicators to identify malicious software~\cite{guo2023zeroday} . Although such approaches remain effective against known threats, they often struggle to detect evolving malware variants that employ obfuscation, polymorphism, API substitution, and behavior-altering execution strategies~\cite{bilot2024survey,amer2025graphshield} . Even minor modifications to binary structure or execution behavior can allow malicious software to evade static detection systems, reducing their effectiveness in modern cybersecurity environments~\cite{guo2023zeroday} . To address these limitations, behavioral malware analysis has emerged as an important research direction in cybersecurity~\cite{bilot2024survey,amer2025graphshield} . Unlike static approaches that analyze binaries prior to execution, behavioral analysis focuses on monitoring runtime activities such as API interactions, process behavior, file operations, registry modifications, and network communication patterns~\cite{amer2025graphshield} . Machine learning and deep learning techniques have been explored for this purpose due to their ability to learn complex behavioral patterns directly from execution traces~\cite{bilot2024survey,guo2023zeroday,li2024heterogeneous} . However, many existing approaches continue to face important challenges in effectively modeling the dynamic and evolving nature of malicious activity~\cite{bilot2024survey,guo2023zeroday,haghshenas2023temporal} . One major limitation of conventional machine learning approaches is their dependence on flat handcrafted feature representations that often discard structural relationships and execution ordering between behavioral events~\cite{bilot2024survey,guo2023zeroday} . Although Graph Neural Networks (GNNs) improve structural behavioral analysis by modeling interactions between system entities as graph-structured data, many existing graph-based approaches continue to represent execution traces as static graphs without explicitly incorporating temporal execution dynamics~\cite{bilot2024survey,haghshenas2023temporal,wang2019matchgnet} . As a result, important behavioral characteristics such as operation ordering, behavioral acceleration, frequency variation, and burst activity may not be adequately captured during learning~\cite{amer2025graphshield,haghshenas2023temporal} . Similarly, recent advances in Large Language Models (LLMs) and semantic embedding techniques have demonstrated promising capability in improving contextual understanding of API behavior and execution semantics~\cite{amer2025graphshield,mimura2022nlp} . Semantic embeddings can improve robustness against API obfuscation and naming variation by learning contextual relationships between functionally related operations~\cite{amer2025graphshield,mimura2022nlp} . Nevertheless, many existing semantic approaches remain limited in their ability to jointly model temporal behavioral evolution and heterogeneous structural dependencies within dynamic execution environments~\cite{amer2025graphshield,haghshenas2023temporal} . These limitations represent a significant challenge for modern cybersecurity systems because malicious behavior is inherently temporal, relational, and context-dependent~\cite{bilot2024survey,haghshenas2023temporal} . In practical environments, threats often evolve rapidly during execution, interact with multiple system entities simultaneously, and exhibit behavioral patterns that differ substantially across attack variants~\cite{bilot2024survey,amer2025graphshield} . Consequently, improving behavioral generalization, adaptive threat detection, and temporal behavioral modeling remains an important research problem in cybersecurity~\cite{bilot2024survey,guo2023zeroday,amer2025graphshield} . Addressing these challenges has both academic and practical significance. From a research perspective, improving the integration of semantic understanding, structural reasoning, and temporal behavioral analysis may contribute toward more robust and generalizable threat detection methodologies. From an operational perspective, improved behavioral detection systems could strengthen early-stage threat identification, reduce detection delays, and improve resilience against evolving cyber attacks targeting critical infrastructure and organizational systems.

1.2 Thesis Objectives
This thesis aims to investigate the application of heterogeneous Temporal Graph Neural Networks (TGNNs) for dynamic behavioral threat detection in modern cybersecurity environments. The study focuses on improving behavioral malware analysis through the integration of heterogeneous graph representation learning, semantic contextual understanding, and temporal execution modeling within a unified detection framework. In particular, the research explores how semantic embeddings, structural graph reasoning, and temporal behavioral dynamics can jointly improve threat detection capability, behavioral generalization, and robustness against evolving malicious activity.The primary objectives of this thesis are structured as follows:

Objective 1: To develop a schema-aware heterogeneous behavioral graph representation framework capable of transforming sandbox-generated execution traces into graph-structured behavioral data containing API calls, processes, files, registry objects, and network interactions. The objective is to preserve structural and relational dependencies between system entities that are often lost in conventional vector-based behavioral representations. 
Objective 2: To investigate the integration of pretrained Large Language Model (LLM)-based semantic embeddings into behavioral threat analysis in order to improve contextual understanding of API behavior and strengthen robustness against API obfuscation, naming variation, and evolving execution patterns. The study aims to analyze whether semantic representations can improve behavioral generalization compared to conventional handcrafted behavioralfeatures.

Objective 3: To design and evaluate a heterogeneous Temporal Graph Neural Network (TGNN) architecture integrating heterogeneous graph message passing, Hybrid GAT-SAGE aggregation, and bidirectional LSTM-based temporal sequence modeling for dynamic threat detection. This objective focuses on investigating how structural graph relationships and temporal execution dynamics can jointly improve behavioral threat classification.
Objective 4: To investigate the effectiveness of engineered temporal behavioral features including operation frequency, behavioral acceleration, and burst activity characteristics in capturing evolving malicious execution patterns. The objective is to assess whether explicit temporal behavioral modeling can improve detection capability compared to static graph-based approaches.
Objective 5: To develop and evaluate an adaptive fusion mechanism capable of integrating semantic, structural, and temporal behavioral representations within a unified learning framework. The study aims to analyze how different behavioral dimensions contribute toward threat classification and whether integrated multi-branch behavioral modeling improves detection robustness.
Objective 6: To evaluate the proposed framework against multiple baseline approaches including static machine learning models, sequential deep learning architectures, static Graph Neural Network models, and semantic behavioral analysis approaches using evaluation metrics such as accuracy, precision, recall, F1-score, AUPRC, false positive rate, and time-to-detect performance.
Objective 7: To assess the behavioral generalization capability of the proposed framework using family-separated evaluation protocols designed to analyze robustness against evolving attack variants and diverse malicious behavioral patterns across different threat categories.
This research ultimately aims to contribute toward the development of more adaptive, robust, and semantically informed behavioral threat detection systems capable of modeling the temporal, structural, and contextual characteristics of modern cyber threats. By integrating semantic understanding, temporal behavioral analysis, and heterogeneous graph reasoning within a unified framework, the study seeks to strengthen dynamic cybersecurity analysis and improve intelligent behavioral threat detection in evolving attack environments.

2 Literature Review
The rapid evolution of modern cyber threats has increased the importance of intelligent behavioral threat detection within cybersecurity research. While traditional signature-based detection systems remain effective against previously observed malware variants, threats employing obfuscation, polymorphism, API substitution, and behavior-altering execution strategies continue to challenge the effectiveness of existing detection approaches. As a result, recent research has increasingly focused on behavioral analysis techniques capable of modeling malicious activity through execution behavior rather than relying solely on static signatures or handcrafted rules. This literature review examines the progression of threat detection research from traditional signature-based and static machine learning approaches toward recent deep learning, Graph Neural Network (GNN), Temporal Graph Neural Network (TGNN), and semantic embedding-based behavioral analysis methods. Particular attention is given to studies investigating temporal execution modeling, heterogeneous graph representations, API sequence analysis, semantic contextual understanding, and early-stage behavioral threat detection within dynamic cybersecurity environments.  The review process involved systematic exploration of academic databases and research repositories including Google Scholar, IEEE Xplore, ACM Digital Library, SpringerLink, ScienceDirect, arXiv, and proceedings from major cybersecurity and machine learning conferences. The literature search incorporated combinations of keywords such as “behavioral threat detection,” “dynamic malware analysis,” “Graph Neural Networks,” “Temporal Graph Neural Networks,” “heterogeneous graph learning,” “semantic embeddings,” “LLM-based malware detection,” “API behavioral analysis,” and “early-stage ransomware detection.” Additional relevant studies were identified through citation tracing and reference analysis from closely related research works. Following relevance filtering and comparative analysis, the reviewed literature provides a broad foundation for understanding current advances and limitations in behavioral threat detection research. The surveyed studies further indicate a continuing research gap in effectively integrating semantic understanding, temporal execution dynamics, and heterogeneous structural reasoning within a unified behavioral threat detection framework, thereby motivating the research presented in this thesis.
